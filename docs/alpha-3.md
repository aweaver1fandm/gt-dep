# Alpha 3 — Live Tracker Foundation

Alpha 3 replaces the temporary game-ready screen with the first live tracking interface.

Implemented in this release:

- Touch-first landscape live game screen
- Interactive SVG rink
- Exact Grade A geometry ported from Version 1
- Shared Grade A polygon for drawing and shot classification
- Tap-the-rink shot recording
- York/opponent shot assignment based on defended end
- Goal conversion for the most recent shot
- Undo for the most recent shot
- End-period persistence and snapshot behavior
- Period summary for shots on goal, Grade A shots, and goals
- Hidden accessible radio inputs on the Alpha 2 goalie cards

Penalty, faceoff, and goalie-switch commands remain visible but disabled for later alphas.
