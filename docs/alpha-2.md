# Alpha 2 — Game Setup

Version `2.0.0-alpha2` adds the first complete user workflow to the Version 2 PWA.

## Included

- Touch-first York Devils game setup screen based on the approved landscape mockup.
- Opponent team name and game date entry.
- Regulation period length with a 17-minute default and 1–60 minute validation.
- Starting goalie choices for Anthony, Mason, or Other.
- Conditional goalie-name field when Other is selected.
- Accessible inline validation and save-error reporting.
- Immediate creation and persistence of active games in IndexedDB.
- Home-screen New Game navigation.
- Continue Game activation when an active game exists.
- Temporary saved-game confirmation screen until the live rink arrives in Alpha 3.

## Deliberately deferred

- Live rink and shot placement.
- Game clock and period controls.
- Goals, penalties, faceoffs, and goalie switches.
- Completed-game browsing.
- Recovery-management interface.
