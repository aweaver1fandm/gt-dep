# Design notes

## Fixed assumptions

- The primary team is always the York Devils.
- The complete rink is visible during live tracking.
- The user selects which end York defends in the first period.
- Ends switch automatically each period and may be changed manually.
- Grade A geometry is fixed to the supplied paper shot chart.
- The nine-zone target is recorded only for opponent goals.
- Live team cards show the current period.
- The Game Totals card shows full-game totals for both teams.

- Every rink tap records a shot.
- The Goal button converts the most recently recorded shot into a goal.
- Goalie choices are Anthony, Mason, or Other.

- Game setup no longer includes a location field.
- Each game row has an explicit Delete button with confirmation.
- Deleting a game also deletes every associated shot event and derived statistic.
